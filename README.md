# Hands-on Cybersecurity Labs

A collection of practical cybersecurity labs, experiments, and CTF challenges focused on learning through hands-on work.

## Focus Areas

### Offensive Security

Practical labs focused on understanding attacks, attack techniques, and security testing in controlled environments.

### Defensive Security

Labs focused on detecting, investigating, and analyzing security events and attacks using network and system monitoring techniques.

### Digital Forensics

Practical work focused on collecting, examining, and analyzing digital evidence to understand security incidents.

### Incident Response

Labs focused on investigating security incidents, understanding what happened, and analyzing the available evidence.

### CTF

Capture The Flag challenges covering different areas of cybersecurity, including network security, web security, cryptography, forensics, and system security.

## Goal

The goal of this repository is to build practical cybersecurity skills by studying attacks, detecting them, investigating security incidents, and solving security challenges.

The repository will grow over time as I work with different security concepts, techniques, and tools.
